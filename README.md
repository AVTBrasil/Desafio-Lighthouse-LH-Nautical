# Desafio-Lighthouse-LH-Nautical

Solução do desafio técnico do Programa Lighthouse (Indicium), em que atuei como analista de dados da LH Nautical, uma empresa fictícia do setor náutico. A partir de 24 arquivos CSV brutos, o projeto cobre o ciclo completo de uma análise de dados:

Análise exploratória (EDA) e tratamento dos dados
Consultas em SQL com DuckDB
Análise de vendas e de clientes
Previsão de demanda
Sistema de recomendação
Dashboard final com os principais insights para o negócio
